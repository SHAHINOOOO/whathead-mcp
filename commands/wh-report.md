Using the Whathead MCP, build a performance report for: $ARGUMENTS

1. `list_accounts`, then confirm platforms, accounts, and date range (default: last 7 days
   vs prior 7 days).
2. `get_performance_report` per platform: spend, impressions, clicks, CTR, CPC, CPM,
   conversions, CPA, ROAS.
3. Put platforms side by side with week-over-week deltas and flag the biggest movers.
4. Give 3–5 insight bullets and one action per platform.
5. If I ask, `export_report` to CSV or Google Sheets and return the link. Read-only — no changes.
