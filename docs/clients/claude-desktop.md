# Connect Whathead to Claude Desktop & Web

1. Open **Settings → Connectors**.
2. Click **Add custom connector**.
3. Paste the URL:

   ```
   https://whathead.com/mcp
   ```

4. Complete the OAuth login in your browser.
5. Start a new chat — the Whathead tools are now available.

**Verify:**

> "Use Whathead to list my connected ad accounts."

> **Note:** Remote MCP connectors require a Claude plan that supports custom connectors.
> If you don't see the option, update the app or check your plan.
