# Connect Whathead to Windsurf

Add the server to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "whathead": {
      "serverUrl": "https://whathead.com/mcp"
    }
  }
}
```

Open **Windsurf → Settings → Cascade → MCP Servers**, refresh, and complete the OAuth login.

**Verify:**

> "Use Whathead to list my connected ad accounts."
